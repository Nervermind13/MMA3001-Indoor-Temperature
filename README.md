MMA3001 — Indoor Temperature Analysis
Project Overview
This project analyses indoor temperature measurements collected by environmental sensors during 2024. It uses Python and numerical methods to investigate daily temperature patterns, compare regression models, estimate average temperatures, and evaluate accuracy and computational performance.

The main sensor analysed is 6012002000869, using readings from 1 May to 31 December 2024.
Objectives
- Extract and clean temperature readings from a compressed sensor dataset.
- Visualise temperature changes and calculate average temperatures by hour.
- Compare linear, cubic polynomial, and piecewise linear regression models.
- Evaluate model accuracy using separate training, validation, and test data.
- Calculate time-weighted daily average temperatures using the trapezoidal rule.
- Test numerical accuracy, robustness, repeatability, runtime, and memory use.

How to Run
1. Download or clone the repository.
2. Install Python 3 and Jupyter Notebook.
3. Install the required packages:
   pip install numpy pandas matplotlib pytest jupyter
4. Open temperature_analysis (2).ipynb in Jupyter Notebook or VS Code.
5. Select a Python kernel with the packages installed.
6. Run the notebook from top to bottom, starting with the cell that creates temperature_tools.py.
The notebook attempts to download the ZIP dataset from the project's GitHub repository. If the download fails, it looks for 5EnvSensor_MayToDec2024_180kRows.zip in the working directory. Internet access or a local copy of the dataset is therefore needed.
Methodology
1. Data Loading and Cleaning
The program reads the CSV inside the ZIP file in chunks and keeps readings for the selected sensor. It extracts temperature values from JSON records, converts timestamps to Melbourne local time, and removes missing, duplicate, or invalid readings.
2. Temperature Pattern Analysis
Temperature is plotted over the available dates. Readings are also grouped by hour to show the average daily temperature pattern.
3. Regression Modelling
Three model types are investigated:
- Linear regression: represents temperature with a straight line.
- Cubic polynomial regression: uses a third-degree polynomial to capture curved patterns.
- Piecewise linear regression: fits separate straight lines across different periods of the day.
The notebook compares models using validation and test errors, including RMSE and MAE. The model is selected using validation results before its final test performance is reported.
4. Numerical Integration
The trapezoidal rule is used to calculate time-weighted daily average temperatures. These are compared with simple arithmetic averages to examine the effect of irregular sampling intervals.
5. Testing and Optimisation
The project includes automated tests and performance investigations covering:
- Loading and JSON parsing time
- Peak memory use
- Profiling and stage timing
- Computational cost and scalability
- Model settings and training-data requirements
- Numerical stability
- Robustness to simulated faulty sensor readings
- Repeatability of results
Main Findings
The notebook's final design discussion identifies the piecewise linear model as the preferred model, using boundaries at 06:00 and 08:00. It also recommends filtering invalid readings and fitting models to hourly averages to reduce computation while maintaining accuracy.

Processing only the selected sensor, instead of parsing all sensors, reduces unnecessary work. Chunked loading also helps limit memory usage. The notebook contains the detailed plots, model comparisons, and performance measurements supporting these conclusions.
