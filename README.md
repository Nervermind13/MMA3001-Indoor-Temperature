# MMA3001 — Indoor Temperature Analysis

## Project Overview
This project analyses indoor temperature data collected from environmental sensors in 2024 using Python and numerical methods. The aim is to understand temperature patterns, compare regression models, calculate average temperatures, and evaluate accuracy and performance.

## Objectives
- Load and clean sensor temperature data.
- Visualise temperature changes and hourly averages.
- Compare linear, cubic polynomial, and piecewise linear regression models.
- Evaluate model accuracy using RMSE and MAE.
- Calculate daily average temperatures using the trapezoidal rule.
- Test accuracy, robustness, runtime, and memory usage.

## Methodology

### 1. Data Cleaning
The dataset is filtered to select the required sensor. Missing, duplicate, and invalid temperature readings are removed. Timestamps are converted to Melbourne local time.

### 2. Temperature Analysis
Temperature readings are plotted over time. Hourly averages are calculated to identify daily temperature patterns.

### 3. Regression Models
Three regression methods are compared:
- Linear regression
- Cubic polynomial regression
- Piecewise linear regression

Model performance is evaluated using RMSE and MAE on validation and test data.

### 4. Numerical Integration
The trapezoidal rule is used to calculate time-weighted daily average temperatures. Results are compared with simple arithmetic averages.

### 5. Testing and Performance
The project evaluates numerical accuracy, runtime, memory usage, robustness to faulty readings, repeatability, and computational efficiency.

## Main Findings
The piecewise linear model was selected as the preferred model, using boundaries at 06:00 and 08:00. Filtering invalid readings and using hourly averages can improve computational efficiency while maintaining model accuracy.
